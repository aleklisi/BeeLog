# Spec Delta

## ADDED Requirements

### Requirement: NFC actions use blue styling
Actions for copying, assigning, or reading an NFC link or tag from a hive MUST use a high-contrast blue treatment in light and dark themes.

#### Scenario: Use an NFC action from a hive view
- **WHEN** a user views or activates an NFC action for a commercial hive in either theme
- **THEN** the action appears blue with readable text and visible hover and keyboard-focus states
