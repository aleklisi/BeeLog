# Spec Delta

## ADDED Requirements

### Requirement: Correct Back Button Navigation and Voice Dictation
The system SHALL correctly navigate back to the current apiary after moving hives or using NFC links, and voice dictation MUST function properly in commercial hives.

#### Scenario: Back Button and Voice Notes
- **WHEN** a user navigates back from a relocated hive or uses voice dictation for notes
- **THEN** the application MUST return to the correct current apiary view and successfully record voice notes.
