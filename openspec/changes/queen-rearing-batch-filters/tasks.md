# Zadania: Filtry i wyszukiwanie serii hodowlanych

- [ ] Dodać stan wyszukiwania i filtra statusu dla listy serii.
- [ ] Filtrować serie po numerze serii i numerze ula reproduktorki, łącząc kryteria.
- [ ] Zachować istniejące sortowanie pilności po filtrowaniu.
- [ ] Dodać czytelny stan pusty i akcję resetowania kontrolek.
- [ ] Zapewnić etykiety dostępności i tłumaczenia PL/EN.
- [ ] Zaktualizować specyfikację i objąć zachowanie testami.
