# Opis ogólny

Projekt **BeeLog** to nowoczesna aplikacja webowa do kompleksowego zarządzania pasieką, rodzinami pszczelimi oraz trutowiskami.

## Stack technologiczny

- **Frontend**: Aplikacja jednostronicowa (SPA) napisana w języku **Elm** gwarantującym bezpieczeństwo typów i niezawodność stanu.
- **Backend / Baza danych**: Firebase Authentication (logowanie kontem Google) oraz Firestore (baza danych czasu rzeczywistego).

## Uruchomienie i nawigacja

Po uruchomieniu aplikacji użytkownik uwierzytelnia się za pomocą konta Google. Po pomyślnym zalogowaniu następuje przekierowanie do widoku głównego zawierającego listę pasieczysk (własnych oraz udostępnionych).
